# TGBot-with-ChatGPT
Проект демонстрирует, как можно использовать открытые источники данных (например, Википедию) и современные алгоритмы машинного обучения (модели GPT) для создания интеллектуальных систем, способных автоматически обрабатывать и отвечать на вопросы пользователей. Подход можно адаптировать для работы с другими категориями данных и расширить функциональность бота для более сложных взаимодействий.

## /help
Открыть помощь.

Команда `/help` выводит тематику бота, число записей в БД и список доступных команд и их описания.

## /query
Показать пример.

При использовании команды `/query`, бот выводит пример запроса к БД.
